# HORIZON BOT

HORIZON BOT is an open-source Discord bot focused on:

- Game library management
- Cloudflare R2 storage integration
- Open Directory synchronization
- SQLite database management
- AI-assisted server administration
- Automated file processing and delivery

## Features

- Generate download links
- Daily user limits
- Role-based permissions
- Open Directory sync
- Cloudflare R2 upload automation
- SQLite persistent storage
- Railway deployment support

## Tech Stack

- Python
- discord.py
- SQLite
- Cloudflare R2
- Railway

## Status

Actively maintained.
